### Agent Brief

**Category:** enhancement

**Summary:** Make the existing opt-in diagnostics overlay adapt cleanly to
every restyled palette and layout.

**Current behavior:** Diagnostics are correctly absent by default and, when
enabled, report memory, frame time, artwork dimensions, connection state, and
presentation revision. The overlay uses a fixed near-black field, white text,
and white border positioned at the top right; it has no semantic relationship
to light/dark presentation palettes or the new footer and OLED-safe bounds.

**Desired behavior:** Preserve the same data and explicit opt-in contract while
styling and positioning the overlay through readable semantic roles that work
over dark, light, and fixed no-art presentations without displacing normal
content or leaving safe bounds.

**Key interfaces:**

- `DiagnosticsConfiguration` retains the existing strict environment opt-in.
- `Diagnostics::overlay_text()` retains the complete bounded observation set.
- Diagnostic rendering consumes semantic text, field, and border roles that
  remain readable for the active presentation palette.
- Layout policy keeps the overlay clear of Gallery split, full-field copy,
  Output/Zone, and every allowed OLED-protection offset.

**Acceptance criteria:**

- [ ] Diagnostics remain absent unless explicitly enabled and retain all five
      existing observations.
- [ ] Text, field, and border are readable on light, dark, and fixed no-art
      palettes.
- [ ] The overlay remains quiet, non-displacing, and inside OLED-safe bounds
      for both Gallery split and full-field presentations.
- [ ] Tests cover opt-in parsing, content, and adaptive style roles without
      asserting private GTK structure.

**Out of scope:**

- Showing diagnostics by default or adding a network diagnostics surface.
- Expanding the diagnostic data set beyond the observations already present.
