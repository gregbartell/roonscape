**Summary:** Provide a repeatable native capture matrix and visual checklist

**Current behavior:** RoonScape has a shared fixture launcher and a native

decision-focused comparison against the selected prototype.

repeatable native-renderer captures at 3840×2160, 3840×2400, and 1600×900 for

automated contract, then hands physical OLED judgment to the existing human
Reference Deployment acceptance work.

  durable documented format.
- Existing automated seams remain responsible for fixture content, layout
  policy, palette contrast, and runtime behavior.
