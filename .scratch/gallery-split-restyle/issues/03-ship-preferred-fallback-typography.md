# 03 — Ship preferred and fallback typography

**What to build:** Give RoonScape the selected editorial typography without
depending on arbitrary host substitutions: use Palatino Linotype and Segoe UI
as one preferred pair when both are present, otherwise use the complete open
Libre Baskerville and IBM Plex Sans pair.

**Blocked by:** None — can start immediately.

**Status:** done

      Segoe UI when both preferred faces are installed and resolvable.
- [x] If either preferred face is unavailable, Title and Album use Libre

### Agent Brief

**Category:** enhancement

**Summary:** Select the preferred editorial font pair atomically and package a
deterministic offline fallback pair.

**Current behavior:** Renderer CSS names broad serif and sans-serif fallback
stacks. The actual faces therefore depend on the host, preferred and fallback
roles can mix arbitrarily, and RoonScape ships no fonts or font licenses. The
development host resolves both Palatino Linotype and Segoe UI, while the open
fallback pair is not currently installed or packaged.

**Desired behavior:** Use Palatino Linotype with Segoe UI only when both are
resolvable. Otherwise use packaged Libre Baskerville with IBM Plex Sans as a
complete pair, offline and with their license notices. Pango may still provide
glyph-level substitution outside the selected pair's coverage.

**Key interfaces:**

- Typography selection exposes one deterministic preferred-or-fallback choice
  to every display and utility text role.
- Renderer startup makes packaged fallback faces available without installing
  them globally or reaching the network.
- The supported deployment includes the open font files and corresponding
  license notices, but never the proprietary preferred faces.
- Tests can substitute font-availability results to exercise all three host
  conditions without depending on the test machine's installed fonts.

**Acceptance criteria:**

- [x] Preferred-present selects Palatino Linotype and Segoe UI together.
- [x] Preferred-partial and preferred-absent both select Libre Baskerville and
      IBM Plex Sans together, with no mixed pair.
- [x] The fallback faces and licenses ship and load without network or global
      host installation.
- [x] Missing glyphs remain readable through Pango substitution.
- [x] Automated selection checks and representative captures cover both
      complete pairs.

**Out of scope:**

- Redistributing or downloading Palatino Linotype or Segoe UI.
- User-selectable font themes or disabling Pango glyph substitution.

### Implementation Result — 2026-08-15

Implemented in `f5ed5c0` with a standards-review simplification in `ea492dd`.
The renderer registers packaged Libre Baskerville and IBM Plex Sans variable
fonts as private Fontconfig application fonts, selects Palatino Linotype and
Segoe UI only when both host faces resolve, and otherwise selects the complete
open fallback pair. Both OFL notices ship beside the fallback files; no
preferred proprietary font is included.

Native preferred and forced-fallback captures were inspected, and a separate
capture confirmed that Pango substituted a readable glyph for `月`, which is
outside the selected preferred editorial face. The final standards review
reported no hard violations, and the specification review reported no
remaining findings. `npm run check` passed with formatting, type checking,
linting, the complete TypeScript and Rust test suites, and the
two-startup-order IPC restart smoke check.
