**Category:** enhancement

**Summary:** Make the shared fixture family reproduce the selected fictional
release and truthful reference timing.

**Current behavior:** The production Playing fixture uses a different release,
artwork, identity, and timing sample. Its fixed historical `sampledAt` value can
also make a newly launched Playing fixture appear farther advanced or already
clamped instead of opening at the visual reference position. Fixture and live
snapshots already share the same publisher and native renderer path.

**Desired behavior:** Fixture mode opens on Last Light on Phobos at 171 of 266
seconds with the exact prototype artwork, then advances only as a live Playing
sample would. Related fixtures form one coherent family while preserving the
truthful semantics of Paused, Loading, and deliberate edge cases.

- The shared `PresentationSnapshot` fixtures carry the selected release,
  Tracked Output, Tracked Zone, progress, and artwork reference.
- Fixture launch re-anchors Playing `sampledAt` without changing the stored
  baseline or the semantics of non-Playing fixtures.
- The fixture publisher continues to publish the same complete contract used
  by live Roon operation.
- The production artwork asset is byte-for-byte identical to the preserved
  prototype SVG.

- [ ] Edge-case fixtures inherit the reference release except where the named

- [ ] Automated checks compare the artwork bytes, fixture contents, and
